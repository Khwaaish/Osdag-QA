# Test Status Legend

| Status | Use |
| --- | --- |
| **PASS** | The intended behavior was sufficiently observed for the specific recorded scenario. |
| **FAIL** | A reproducible defect or clear discrepancy was observed in the documented scope. |
| **PARTIAL** | Coverage was incomplete or only part of the behavior could be verified. |
| **NOT TESTED** | Planned, but no execution was recorded. |
| **NEEDS INVESTIGATION** | A suspicious result was observed, but defect status or cause is not established. |

Statuses do not imply structural engineering validation. Source-level and synthetic statuses apply only to the isolated path tested. When status evidence conflicts across artifacts, the conflict is described explicitly.
