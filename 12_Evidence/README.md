# Evidence Management

Evidence files from the original QA package are preserved in their intake folders. This directory contains navigation/index material; files have not been moved or renamed. Generic screenshot names are retained as supplied. Evidence links in test reports only identify a screenshot when its visible content was inspected and is relevant.

## Contents

| Subfolder | Intended content | Current state |
| --- | --- | --- |
| `Screenshots/` | Named GUI captures | Existing screenshots remain in original directories; this folder holds this note only |
| `Reports/` | Generated PDF reports | Reports remain under `08_Reports/` |
| `CAD/` | CAD exports | No standalone CAD export located |
| `Logs/` | Validator/source/runtime logs | No standalone logs located |
| `Input_Files/` | `.osi` inputs | Inputs remain in original directories |
| `Issue_Evidence/` | Issue page captures | No issue-submission screenshots located |

Exact duplicate files from the intake package were removed from the current tree; the index maps canonical copies. One `QA Evidence/*.png` file is not decodable as PNG and is not treated as visual evidence.
