# Glossary

| Term | Meaning in this repository |
| --- | --- |
| `.osi` | OsdagBridge input/state file used in save/load checks |
| Input Dictionary | Application data representation of user inputs |
| Output Dictionary | Application data representation of computed/design outputs |
| Output Dock | Desktop UI area displaying analysis/design outputs |
| DCR | Demand-capacity ratio/status displayed by design checks |
| GUI | Graphical user interface |
| Synthetic check | Isolated test using controlled artificial objects/data |
| Runtime test | Test performed in the running application |
| Evidence not located | No corresponding named file found in the inspected package |
